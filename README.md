# Trung Thu 2026

Site + slideshow for Hội Người Việt Stockholm's Trung Thu, Saturday 24 Oct 2026, Danderydsgården.

- `index.html` – the site
- `slides.html` – the slideshow (← → / space, F fullscreen, P autoplay, swipe on phones; `#3` opens slide 3)
- `data.js` – programme and payment details, shared by both

Static, no build. Run locally: `python -m http.server 5240`
